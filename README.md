# 🌾 Argolens – AI-Based Rice Disease Detection App

## 📌 About the Project
Argolens is a Smart Agriculture Application designed to support farmers by using AI technology to detect rice leaf diseases. The application also provides weather information and a platform for farmers to share agricultural knowledge and experiences.

This project was developed as a **competition project** to demonstrate how technology can help solve agricultural problems and support farmers.

## ✨ Key Features
- **Rice Disease Detection:** Uses a CNN-based AI model to identify rice leaf diseases from images.
- **Weather Information:** Provides weather updates to help farmers plan their agricultural activities.
- **Disease Information:** Offers information about rice diseases and their prevention and treatment.
- **Farmer Community:** Enables farmers to share experiences and discuss agricultural issues.
- **User-Friendly Interface:** Designed to make agricultural information accessible to users.

## 🎯 Project Objectives
- To help farmers identify rice diseases more easily.
- To support early disease detection and prevention.
- To provide useful weather information for agricultural planning.
- To encourage knowledge sharing among farmers.
- To apply AI technology to real-world agricultural challenges.
